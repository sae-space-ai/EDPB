### Paso 1: Desplegar la Aplicación

**Opción A: Script Automático (Recomendado)**
```bash
chmod +x deploy.sh
./deploy.sh
```

**Opción B: Manual**
```bash
npm install
npm run build
git init
git add .
git commit -m "EDPB-SUPER-ECOSYSTEM v4.0"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/edpb-super-ecosystem.git
git push -u origin main
# Luego importar en Vercel
```

### Paso 2: Acceder a la Aplicación

1. Abre la URL de Vercel (ej: `https://edpb-super-ecosystem.vercel.app`)
2. Verás el **Dashboard** con estadísticas del sistema

### Paso 3: Explorar las Pestañas

Navega por las **16 pestañas**:

1. 🏠 **Dashboard** - Vista general
2. 🌐 **Ecosystem** - Control del ecosistema
3. 🔥 **Real Test** - Prueba real con trazabilidad
4. 🗺️ **AI Act** - Mapeo de 67 artículos
5. 🤖 **Sub-Agents** - 8 sub-agentes
6. 🔌 **Providers** - 7 proveedores LLM
7. 🧠 **AI Models** - 7 modelos de IA
8. 🛡️ **Security** - 8 herramientas de seguridad
9. 🗄️ **Vector DB** - 3 bases de datos
10. 🏭 **Gigafactory** - 5 gigafactorías
11. 🎯 **Expertise** - Perfil del candidato
12. 🔬 **Evidence** - Motor de evidencias
13. 🧪 **Auto-Test** - Verificación autónoma
14. 🚀 **Projects** - 6 proyectos
15. 📚 **Publications** - 12 publicaciones
16. 🎓 **Training** - Módulos formativos

### Paso 4: Ejecutar la Prueba Real

1. Navega a la pestaña **"🔥 Real Test"**
2. Haz click en **"🚀 Ejecutar Prueba Real"**
3. El sistema ejecuta **8 fases** automáticamente:
   - FASE 1: Inicialización
   - FASE 2: Verificación de componentes (31)
   - FASE 3: Despacho de sub-agentes (8)
   - FASE 4: Generación de evidencias (4)
   - FASE 5: Escaneos de seguridad (8)
   - FASE 6: Consultas a gigafactorías (5)
   - FASE 7: Test de modelos IA (7)
   - FASE 8: Verificación de integridad

4. Cada fase se registra con:
   - **Timestamp** exacto
   - **Hash SHA-256** único
   - **Estado** (success/error)
   - **Detalles** de la operación

5. Al finalizar, verás:
   - **Trazabilidad completa** con todos los hashes
   - **Hash final** de integridad
   - **Botón para exportar** el log JSON
   - **Botón para copiar** el hash final

### Paso 5: Verificar la Trazabilidad

1. **Revisa el log** - Cada entrada tiene un hash SHA-256
2. **Verifica el hash final** - Demuestra integridad
3. **Exporta el JSON** - Para auditoría
4. **Copia el hash** - Para compartir
